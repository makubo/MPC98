# MPC98

MPC98 is a fork of Media Player Classic 6.4.9.1 focused on compatibility with Windows 98.
[Original repo](https://sourceforge.net/p/guliverkli2/code/HEAD/tree/)

**Development note:** This project is developed with AI assistance. I am not a C++ programmer, but I wanted to be able to watch my Jellyfin library in my retro Windows 98 setup.

## Highlights

### Features

Of the current fork compared to MPC 6.4.9.1

1. Jellyfin support
    - library browsing
    - Progressive/HLS streaming
    - stream audio selection
    - playlist integration
